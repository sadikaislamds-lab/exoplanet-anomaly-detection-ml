# exoplanet-anomaly-detection-ml
Anomaly detection in exoplanet data using unsupervised machine learning techniques combined with exploratory data analysis.
# Exoplanet Anomaly Detection (Machine Learning)

## Overview
This project focuses on detecting anomalous patterns in exoplanet data using
unsupervised machine learning techniques. The aim is to identify exoplanets
whose physical or orbital characteristics significantly deviate from typical
observations.

The project combines exploratory data analysis (EDA) with machine learning–based
anomaly detection to better understand unusual planetary features.

---

## Objectives
- Explore key features of exoplanet datasets
- Apply unsupervised machine learning for anomaly detection
- Identify and visualize outliers in planetary parameters
- Interpret anomalies using statistical and visual analysis

---

## Methodology
1. **Data Preprocessing**
   - Handling missing values
   - Feature selection and scaling

2. **Exploratory Data Analysis (EDA)**
   - Distribution analysis
   - Correlation analysis
   - Visualization of planetary parameters

3. **Machine Learning**
   - Unsupervised anomaly detection using machine learning models
   - Detection of outliers based on feature behavior

4. **Visualization & Interpretation**
   - Highlighting anomalous observations
   - Comparing anomalies with normal data points

---

## Machine Learning Techniques Used
- Unsupervised anomaly detection  
- Models such as:
  - Isolation Forest / Local Outlier Factor / One-Class SVM  
  *(depending on implementation in the notebook)*

---

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## Dataset
Exoplanet dataset included in this repository in CSV format.
The dataset contains physical and orbital parameters of confirmed exoplanets.

---

## Results
The model successfully identifies exoplanets that exhibit unusual
characteristics compared to the majority of the dataset. These anomalies are
further analyzed using visual and statistical methods.

---

## Disclaimer
This project is exploratory and educational in nature.
The detected anomalies do not represent confirmed scientific discoveries,
but demonstrate the application of machine learning techniques to astronomical data.
